📚 How I Learn

I believe the best way to learn bioinformatics is to solve real problems and understand every step of the solution.

I use computational tools, documentation, scientific literature and AI-assisted learning as part of this process, but my goal is always to understand:

«Why this method?
Why these parameters?
What are the assumptions?
What could go wrong?
How should the results be interpreted?»

This GitHub is therefore both a portfolio and a record of my continuous learning.
